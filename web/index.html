Sobre a Wiki

☰ Anormalidades

Consulta a base de dados completa de todas as Anormalidades contidas nas instalações. Visualiza stats, nível de risco, tipo de dano e muito mais.

⚙ Filtrar

Pesquisa avançada por múltiplos critérios cumulativos: nome, nível de risco, tipo de ataque, benefício para a instalação e intervalo de E-Boxes.

＋ Gestão de Dados

Inserir novas Anormalidades, actualizar registos existentes ou remover entradas da base de dados MySQL através do formulário JSP.

⚠ Sistema EGO

Cada Anormalidade pode gerar equipamentos EGO — armas e armaduras que os agentes equipam para missões no interior das instalações.
